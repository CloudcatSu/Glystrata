# Mac 版寫出的快照檔（反向驗證用）

對應 `docs/plans/2026-10-13-mac-port-plan.md` 第 5-3 節：確認 Mac 版寫出的 `.gss` 拿到 Windows 版能正常使用。

## 內容

- `筆記.md`：示範文件，內容是最後一版。
- `筆記.md.gss`：Mac 版（`mac-port` 分支，2026/10/14 的建置）實際寫出的快照檔，沒有手動編輯過。

產生方式：在 Mac 版開啟 `筆記.md`，按「立即建立快照」三次，每次之間改過內容；再到快照紀錄視窗幫第二筆加上備註。

| 順序（新到舊） | 內容 | 備註 |
| --- | --- | --- |
| 1 | 開頭多一行、結尾多一行 | 無 |
| 2 | 開頭多一行 | 「Mac 寫的備註：第二版」 |
| 3 | 原始內容 | 無 |

## 請在 Windows 版確認

把兩個檔案放在同一個資料夾，用 Windows 版開啟 `筆記.md`：

1. 快照紀錄列得出三筆，時間、字數、備註都正確。
2. 選一筆按「比較」，新增與刪除的行顯示正確。
3. 選最舊的一筆按「回復」，文件內容變回原始內容。
4. 在 Windows 版再建立一筆快照、改一筆備註後，檔案仍然可以被兩邊讀取。

## 與 Windows 寫出的檔案可能不同的地方

- `sourcePath` 是 Mac 上的路徑（`/Users/Shared/GlystrataDemo/筆記.md`）。
- 欄位依名稱排序，冒號前有空格（Swift 的 `JSONEncoder` 輸出格式）。
- `id` 是大寫的 UUID。
- 時間是 UTC、三位小數秒、結尾 `Z`。

如果其中任何一項讓 Windows 版讀不進去，請回報是哪一項。
