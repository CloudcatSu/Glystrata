# Windows 版 v1.2.3 參考截圖

對應 `docs/plans/2026-10-13-mac-port-plan.md` 第 5-1 節的編號，檔名 `<編號>-<light|dark>.png`。

## 截圖條件

- 程式：`dist/win-x64/Glystrata.exe`，版本 1.2.3（commit `04ff0b4`），設定為全新預設值，只指定主題。
- 比例：這台機器的顯示比例是 200%，所以程式是以「不感知 DPI」模式啟動，讓 WPF 以 96 DPI 繪製，
  得到的就是 100% 比例的畫面。主視窗 1240×760，是程式的預設大小。
- 截法：用 `PrintWindow` 直接取視窗內容，不是從螢幕擷取。所以圖裡**沒有**視窗陰影與 Windows 11 的圓角，
  邊緣就是視窗本身的矩形。選單、右鍵選單這類彈出層是另外取圖後依原位置疊上去的。
- 內容：全部是臨時建立的示範檔案（`C:\GlystrataDemo`），沒有真實文件。

## 與清單不同的地方

- 設定視窗的五個分頁，實際名稱是「一般、編輯器選項、閱讀器選項、群組顏色、快照」。
- 22（閱讀器選項）內容超過一頁，另有 `22b` 是捲到底的畫面。
- 11 另有 `11b`，是「最近開啟過的文件」子選單展開的畫面。
- 29（閱讀器整份）分成 `29-1`、`29-2`、`29-3` 三段，由上到下，相鄰兩段有重疊。
- 02 的未儲存文件是未命名的新文件：已存檔的文件停止輸入 1 秒就會自動儲存，未儲存標記留不住。
- 27 的標題列是灰色的，因為按下「尋找」後焦點會回到編輯器。
- 拖曳的放置指示：`drag-tab-*` 是把第二個 TAB 往右拖到最後一個 TAB 前面的途中，`drag-group-*` 是把第二個群組往上拖到第一個群組前面的途中。
  被拖的項目會變淡，藍線是放開後會插入的位置。
