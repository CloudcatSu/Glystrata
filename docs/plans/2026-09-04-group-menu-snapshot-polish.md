# 群組、選單與快照入口修正實作計畫

**日期：** 2026-09-04
**版本範圍：** 既有 0.0.2 修正

## 目標

- 左側只顯示平面群組名稱與目前群組白點，不在群組底下展開文件或資料夾項目。
- 「移動到群組」選擇器穩定顯示實際群組名稱，並回傳對應群組物件。
- 頂層檔案／編輯／檢視／群組／說明選單改為緊湊、置中且不被快捷鍵欄位撐寬。
- 移除右上角亮／暗主題按鈕，主題只由偏好設定控制。
- 保留檔案選單的快照歷史，並在 TAB 右鍵選單加入目前文件的快照入口。

## 實作範圍

- `src/MDeditor/MainWindow.xaml.cs`
  - 移除主題工具列按鈕與相關事件。
  - 建立緊湊的頂層選單項目。
  - 只建立群組節點，不建立群組項目子節點。
  - 接收 TAB 快照歷史事件。
- `src/MDeditor/Dialogs/InputDialogs.cs`
  - 以明確的群組名稱字串清單顯示選項，再以索引回傳對應群組物件。
- `src/MDeditor/Controls/EditorPaneControl.cs`
  - 在 TAB 右鍵選單加入快照歷史命令。
- `src/MDeditor/Resources/Themes/Light.xaml`、`Dark.xaml`
  - 收窄並置中頂層選單，隱藏頂層快捷鍵欄位，維持亮／暗主題對比與細線分隔。
- `Plan/CHANGELOG.md`
  - 記錄本次 0.0.2 後續修正。

## 驗收

- 建立多個群組後，左側只看到群組名稱；點選群組仍只顯示該群組 TAB。
- 從 TAB 右鍵開啟「移動到群組」時，下拉清單逐項顯示正確群組名稱，移動後虛擬關聯正確。
- 亮／暗主題下，頂層選單文字置中、寬度依內容收縮；右上角不再有主題按鈕。
- 檔案選單與 TAB 右鍵都能開啟快照歷史視窗，並可沿用既有比較／回復／刪除操作。
- Debug build 與既有核心驗證全部通過。
